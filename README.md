# 极光词典 AuroraDict

**离线优先、免费、快速的 Windows 英汉 · 汉英桌面词典。**

单文件、免安装、不依赖任何第三方运行库。内置 **326 万英文词条**与 **12 万中文词条**，自研检索内核，毫秒响应；在线翻译与自动更新均为**可选功能、默认关闭**，需要时一键开启。

## ✨ 功能特性

- **默认离线**：词库本地存储，开箱不联网，断网照常使用；不收集任何个人数据。
- **海量词库**：3,268,005 英文词条（含词形变化、短语、星级、考试标签）+ 121,408 中文词条（含拼音、繁体、多释义）。
- **自研内核**：检索、Trie 索引、中文分词、拼写纠错、词形还原全部自研，零第三方运行库。
- **全新界面（v1.0.4）**：整体排版重设计，控件、文字、按钮布局更合理美观；**双击标题栏即可最大化 / 还原窗口**。
- **精美卡片**：音标、星级、考试标签（牛津 3000 / 高考 / 四六级 / 考研 / 托福 / GRE）、词形变化、中英双释义。
- **在线回退（默认关闭）**：手动开启后，本地未收录时才尝试在线翻译；查询词仅在此时发送至在线服务。
- **自动更新（默认关闭）**：可手动检查或开启启动检查，下载物经 SHA256 校验、更新前自动备份、失败自动回滚，并自动解除下载文件的网络标记。
- **生词本与复习**：收藏生词、闪卡复习，支持导出纯文本与 Anki（TSV）牌组。
- **离线发音**：英文、中文双语音，基于 Windows 内置语音合成。
- **快捷取词**：全局热键 `Ctrl+Alt+D`，可选复制后自动查词。
- **清爽释义**：可一键隐藏中文释义开头的 [网络] / [计] / [医] 等分类标记，直接显示译文（默认开启）。
- **深浅色主题**：自绘界面与滚动条，浅色 / 深色自由切换，滚动条颜色随主题变化。

## 📥 下载与安装

前往 **[Releases 页面](https://github.com/haoeastspeed/AuroraDict/releases/latest)** 下载最新版本：

- 下载 `极光词典.exe`
- 双击即可运行，无需安装、无需联网（界面名称为「极光词典」）

**系统要求**：Windows 10 / 11（**32 位与 64 位均可**，亦兼容 Windows 7 / 8.1），需 .NET Framework 4.5 或更高版本（Win10/11 已自带 4.8，无需另行安装）。

> 💡 国内直连 GitHub 下载较慢，建议开启本地 / 系统代理；软件自动更新会依次尝试官方直连、系统代理与 `127.0.0.1:7890`。

## 🔄 自动更新

自动更新**默认关闭**。你可在「设置 → 软件更新」开启启动检查，或随时点击「检查更新」。发现新版本后一键下载，下载物经 SHA256 / 大小校验，覆盖前自动备份、失败自动回滚，下载完成后自动解除网络下载标记；若直连较慢，会依次尝试系统代理与本地代理。

## 🔒 隐私说明

- 词典数据与个人设置（生词本、历史记录）均保存在本机，不上传服务器。
- 开箱默认不发起任何网络请求；仅当你手动开启在线回退或自动更新并使用时才会联网，离线时绝不请求。
